# 3d-print-projects

3D-printable designs written as code. Each model is a Python script that builds the solids with [manifold3d](https://github.com/elalish/manifold) and exports STLs with [trimesh](https://trimesh.org/).

## Projects

### `pi5-case/`: wall-mount Raspberry Pi 5 case

A two-part case (base and lid) that hangs on two wall screws by keyhole slots, with the USB/Ethernet end pointing down. A printable drill template marks where the wall screws go.

| Version | Hardware stack | How the stack is held |
| --- | --- | --- |
| [`v1`](pi5-case/v1) | Official Active Cooler + Raspberry Pi M.2 HAT+ | M2.5 heat-set inserts in the case standoffs |
| [`v2`](pi5-case/v2) | 52Pi U2500 HAT (dual 2.5GbE + M.2 NVMe), no cooler | 4x M2.5 x 16 button-head screws from the back of the case into the HAT's standoffs |

Each version directory holds the script, the generated STLs, and a `.3mf` project. `v2` also has an assembly guide: [`assemble.html`](pi5-case/v2/assemble.html).

Printed parts:

- `pi5_case_base.stl`: prints back-down, as exported
- `pi5_case_lid.stl`: exported flipped, flat outer face on the bed
- `pi5_drill_template.stl`: hold it on the wall and mark through the holes; they are the final screw positions

The lid fastens with M3 self-tapping screws into the corner bosses. The wall screws are #6/#8 pan head or 4 mm.

## Regenerating the STLs

```sh
pip install manifold3d trimesh numpy
cd pi5-case/v2
python3 pi5_wall_case.py
```

The script writes the STLs into the current directory and prints each part's size, volume, and whether it is watertight.

To change the design, edit the constants in the `parameters` block at the top of the script (wall thickness, clearances, keyhole positions, and so on) and run it again. The `.3mf` files are not regenerated by the script.
